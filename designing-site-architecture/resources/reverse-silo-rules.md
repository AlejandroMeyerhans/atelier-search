# Kyle Roof's Reverse Silo — Linking Rules Reference

## The 6 Rules

### Rule 1: Spoke → Hub (MANDATORY)
- Every spoke links UP to its hub
- Contextual body link, first 3 paragraphs
- Exact-match or close-variant anchor text
- ONE link per spoke to hub

### Rule 2: Hub → Spokes (STRATEGIC)
- Hub links DOWN to ALL its spokes
- Body content or "Related Topics" section
- Spoke's H1 keyword as anchor
- Distributes authority to the silo

### Rule 3: Spoke ↔ Spoke Same Silo (DAISY CHAIN)
- Spokes link to the NEXT spoke sequentially
- Circular: Spoke 1 → 2 → 3 → ... → N → 1
- Creates PageRank flow loop within silo
- Bottom of body content

### Rule 4: Spoke → Spoke Cross-Silo (FORBIDDEN)
- ❌ NEVER link between spokes in different silos
- This dilutes topical relevance
- Violates silo containment principle
- The single most important rule

### Rule 5: Hub → Hub Bridges (STRATEGIC, LIMITED)
- Hub pages CAN link to other hubs
- Maximum 3 bridges per hub
- Only where semantic relevance is clear
- The ONLY acceptable cross-silo connection

### Rule 6: Body Links Only (CONTEXTUAL)
- All silo links in body content
- Nav/footer links don't count as silo links
- Nav can exist for UX, but silo logic lives in content
